# La Ruta Eventos

Sitio web del salón de eventos **La Ruta**, en Río Primero, Córdoba, Argentina.

Salón multiuso con servicio de catering y decoración propios: fiestas de 15,
casamientos, cumpleaños, eventos corporativos y espectáculos.

## Sobre el sitio

Una sola página en HTML, CSS y JavaScript, sin dependencias ni proceso de build.
Las fotos van incrustadas en el propio archivo, así que `index.html` funciona
por sí solo: alcanza con abrirlo o servirlo como archivo estático.

El mapa de la sección de contacto es un iframe de Google Maps y necesita
conexión a internet para cargar.
